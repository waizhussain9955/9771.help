# 9771.help — Pakistan Petrol Relief Scheme 2026 Helper Portal

An independent, mobile-first, bilingual informational portal and interactive SMS generator for Pakistan's **9771 PM Petrol Relief Scheme (Rs. 100/Litre Subsidy)**.

🌐 **Live Domain:** [https://9771.help/](https://9771.help/)

---

## 🚀 Key Features

- **Interactive 9771 SMS Builder:** Client-side form generating the exact `REG [CNIC] [Vehicle] [Province] [DDMMYYYY]` format.
- **1-Click Mobile SMS Deep Link:** Launches native mobile SMS app with `sms:9771?body=...` pre-filled.
- **At The Pump? Send TOK:** 1-click shortcut to request the digital fuel voucher before visiting the petrol station.
- **Bilingual (English & اردو):** Instant one-click language toggle with authentic RTL and Noto Nastaliq Urdu typography.
- **Quota & Relief Calculator:** Calculates maximum monthly savings (20L for bikes/rickshaws = Rs. 2,000; 30L for cars ≤800cc = Rs. 3,000).
- **Visual Guides & Photos:** Authentic photos of Pakistani transport, fuel stations, and an Excise Smart Card guide.
- **100% Client-Side Privacy:** No database, no backend transmission of CNIC or vehicle details.
- **SEO Ready:** Complete Open Graph, Twitter cards, `robots.txt`, `sitemap.xml`, and Google JSON-LD schema (`WebSite` & `FAQPage`).

---

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Semantic markup, Vanilla CSS with custom properties, zero heavy frameworks.
- **JavaScript (ES6):** Pure Vanilla JS for dynamic bilingual state, SMS string generation, and modal/toast handlers.
- **Deployment:** Zero-build, static site ready for Cloudflare Pages, Vercel, GitHub Pages, or any web server.
